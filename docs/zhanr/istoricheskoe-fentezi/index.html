Навола — Паоло Бачигалупи

В процветающем торговом городе-государстве Навола, напоминающем Флоренцию эпохи Ренессанса, власть принадлежит нескольким олигархическим семьям. Самая могущественная из них — семейство ди Регулаи, владеющее огромным банком. Их богатство способно покупать…
