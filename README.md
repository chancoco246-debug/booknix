# Booknix

Витрина Telegram-канала [«Фантастика | Фэнтези | Переводы | Книги»](https://t.me/fantastica_perevody), сайт **https://booknix.net**.

## Как устроено

| Папка | Что там |
|---|---|
| `data/books.json` | все книги (название, автор, аннотация, жанры, полка, ссылка на пост…) |
| `data/settings.json` | название канала, ссылка, контакт, текст «О канале» |
| `src/style.css`, `src/app.js` | дизайн и логика сайта |
| `tools/import_from_claude.py` | забирает книги и обложки из версии сайта на claude.ai |
| `tools/build.py` | собирает готовый сайт в `public/` |
| `public/` | готовый сайт — именно его показывает хостинг |

## Как обновлять

Книги добавляются и редактируются в админке версии сайта на claude.ai, как раньше.
Потом в чате с Claude пишем «обнови сайт», и он делает так:

```bash
python3 tools/import_from_claude.py путь/к/index.html   # книги + обложки (WebP)
python3 tools/build.py                                   # страницы, sitemap, превью
git add -A && git commit -m "Обновление книг" && git push
```

После `git push` хостинг сам выкладывает новую версию примерно за минуту.

## Что генерируется

* главная `/` и страница каждой книги `/knigi/<id>/` со своим заголовком, описанием, картинкой для превью в соцсетях и разметкой schema.org/Book;
* `sitemap.xml` и `robots.txt` для поисковиков;
* `404.html`.
